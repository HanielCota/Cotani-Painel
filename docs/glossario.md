# Glossário de termos da interface

Use estes termos em todo texto visível (painel, e-mails, mensagens de erro).

| Termo | Uso | Evite |
| --- | --- | --- |
| **negócio** | O estabelecimento do cliente Cotani no painel ("seu negócio", "trocar de negócio", "dados do negócio"). | loja, empresa, estabelecimento |
| **unidade** | Cada local adicional de um negócio no plano Empresa. | filial, loja |
| **Empresa** | Somente o **nome do plano** ("plano Empresa", "assinatura Empresa"). | usar como sinônimo de negócio |
| **estabelecimento / local** | Somente nas telas do **cliente final** (agendamento público, sucesso, cancelamento), onde "negócio" soa estranho. Prefira o nome do negócio quando estiver disponível. | loja, empresa |

Concordância: "negócio" é masculino ("o negócio suspenso", "este negócio", "um negócio ativo").

O código e o banco continuam usando `Clinic`/`clinicId` e as URLs `/admin/lojas` não mudam; o glossário vale para o texto exibido.
Valores gravados no banco (ex.: o motivo "Arquivada pelo administrador da empresa", usado para reconhecer unidades arquivadas) **não** devem ser traduzidos.
